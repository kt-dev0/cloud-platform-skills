# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. GKE ranges

**Prompt:** "Plan IP ranges for 10 GKE clusters in Shared VPC."

**Expected behaviour:** Produces subnet and secondary range plan sized for growth, with subnet-level networkUser grants.

## 2. Hybrid

**Prompt:** "Connect our data center to GCP with 99.99% availability."

**Expected behaviour:** Designs HA VPN or redundant Interconnect with Cloud Router and documents SLA requirements.
