# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. Org logging

**Prompt:** "Centralize all audit logs from our org."

**Expected behaviour:** Creates an org aggregated sink to a central log bucket, enables Data Access logs for sensitive services, and sets retention.

## 2. Cost

**Prompt:** "Cloud Logging costs are rising."

**Expected behaviour:** Identifies top log sources and proposes exclusion filters and flow log sampling while keeping audit logs.
