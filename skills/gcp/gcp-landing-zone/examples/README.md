# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. New org

**Prompt:** "Set up a Google Cloud landing zone for our company."

**Expected behaviour:** Confirms org and admin groups, recommends the enterprise foundations blueprint, proposes folders and org policy baseline, and plans with confirmation.

## 2. Brownfield

**Prompt:** "We have 80 projects with no folders. How do we fix this?"

**Expected behaviour:** Proposes a target hierarchy and a phased project move plan with policy-impact analysis per move.
