# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. New tenancy

**Prompt:** "Set up our new OCI tenancy properly."

**Expected behaviour:** Recommends the OCI Core Landing Zone, proposes compartments, groups, Cloud Guard, tagging and budgets; plans with confirmation.

## 2. Multi-entity

**Prompt:** "We have three business units sharing one tenancy."

**Expected behaviour:** Recommends the Operating Entities Landing Zone with delegated administration.
