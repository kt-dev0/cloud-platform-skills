# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. CIS notifications

**Prompt:** "Set up the CIS-required event notifications."

**Expected behaviour:** Creates topics and Events rules for IAM, network and Cloud Guard changes in the right regions.

## 2. SIEM

**Prompt:** "Send OCI audit logs to our SIEM."

**Expected behaviour:** Configures Connector Hub to Streaming (or Object Storage) with least-privilege policies.
