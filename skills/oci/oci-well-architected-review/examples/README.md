# Examples

> These are starting scenarios. Contributors: after you run one with an agent, add notes on what actually happened.

## 1. CIS check

**Prompt:** "Is our OCI tenancy CIS compliant?"

**Expected behaviour:** Runs the read-only CIS compliance script and Cloud Guard review, and maps findings to the four framework areas.

## 2. Design review

**Prompt:** "Review this OCI design for our ERP migration."

**Expected behaviour:** Assesses AD/FD placement, DR, network exposure and IAM, marking unknowns as unable to verify.
