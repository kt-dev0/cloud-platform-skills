# Well-Architected frameworks by provider

Every skill maps its recommendations to the pillars of **its own provider's** framework. Use the keys below in the `metadata.pillars` frontmatter field, and include one row per pillar in the skill's alignment table.

## Azure: Microsoft Azure Well-Architected Framework

Source: https://learn.microsoft.com/azure/well-architected/

| Pillar | Key |
|---|---|
| Reliability | `reliability` |
| Security | `security` |
| Cost Optimization | `cost-optimization` |
| Operational Excellence | `operational-excellence` |
| Performance Efficiency | `performance-efficiency` |

Companions: Cloud Adoption Framework (https://learn.microsoft.com/azure/cloud-adoption-framework/), Azure Architecture Center, WAF service guides, Microsoft Cloud Security Benchmark, Azure Verified Modules (https://azure.github.io/Azure-Verified-Modules/).
